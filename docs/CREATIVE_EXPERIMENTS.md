# Carrier improvement experiments

The neural comparison reuses the four prior holdout covers and the same 16- and 32-bit targets. Every variant keeps the two-level RGB cap and a 100-step limit. The unchanged baseline was recorded earlier on the same host. Timing is descriptive because process load differed.

- **Smooth.** Optimize a quarter-resolution perturbation grid and bilinearly upsample it before adding it to the input. Pixel values are quantized before each model evaluation, as in the baseline.
- **Transform-aware.** Optimize both the clean view and views through real JPEG 80 with a straight-through gradient approximation, and a differentiable 80% bilinear resize.
- **Combined.** Optimize the smooth grid with the same additional views.

JPEG 70, a 75% resize, crop positions and a synthetic thumbnail with JPEG 85 are evaluation conditions. The carrier remains a frozen SqueezeNet and retains the same decoder.

The separate luminance experiment uses the existing 96-byte authenticated frame, three replicas, spacing three, and the same two-level RGB cap. It tests the fixed lattice against a dithered lattice with independent phase offsets generated by HMAC-SHA256 and SHAKE256 from a separate 32-byte carrier key. The experimental key is a public test fixture. Each matched pair uses the same cover and codeword. The carrier key is separate from the encryption passphrase. The dithered profile is experimental and supports aligned extraction in this test. The CLI uses the original lattice. A separate pilot tests dither-aware scale search after a 75% resize and JPEG 70 without supplying the original dimensions.

Detection measures the previous fixed-phase protocol score and the generic 8×8 edge statistic using the same leave-one-cover-out threshold procedure. A detector that knows or can infer the dither key, a larger corpus, or other steganalysis methods may give different results.

## Reproduce

```sh
python -m experiments.neural_robustness
python -m experiments.phase_dither
python -m experiments.phase_resize
```

The benchmark inputs and prior baseline are included in the archive. Per-cover data is in `benchmarks/neural-robustness/` and `benchmarks/phase-dither/`.

## Interpretation

Optimizing through the actual JPEG and resize transforms modestly improved JPEG and thumbnail recovery on the neural branch. It also lost one exact PNG result and increased median encoding time, with no crop gain. The smoother perturbation improved PSNR but lowered complete recovery. These outcomes favor retaining the clean neural default and keeping the alternative objective as a research option.

The shifted luminance lattice sharply reduced discrimination by the tested fixed-phase score. After JPEG the fixed-phase detector flagged ten dithered images, but also flagged nine clean images at its cross-validated threshold. The generic grid statistic still flagged twelve of fourteen marked PNGs in both arms. This is a detector-specific result. The shifted lattice also lost one file at each tested JPEG quality and two in the resize arm relative to the fixed lattice. It remains experimental and needs the independent carrier key, expected profile, and the message passphrase. No blind detector or attack-resistance guarantee follows from this sample. The same-size and resize arms used different fresh codewords per cover.

All 26 automated tests passed.
