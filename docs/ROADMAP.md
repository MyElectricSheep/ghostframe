# Research roadmap

The working endpoints are preserved-PNG neural messages and a separate conventional luminance carrier for selected image transformations. Their measured limits are in [goal verification](GOAL_STATUS.md).

Next experiments with different evidence requirements are an independent macOS or GPU run, a larger held-out cover corpus, native device screenshots and opt-in real delivery channel tests. A detector evaluation should use independent covers and more than one steganalysis baseline. Any higher-capacity carrier should be compared at equal visual distortion with a fixed recovery target. A dead-drop comparison becomes a separate service experiment if longer payloads become an explicit requirement.

User-interface work is outside the current scope.
